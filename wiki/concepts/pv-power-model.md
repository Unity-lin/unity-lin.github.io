# 태양광 출력 모델

## 최종 식 ([[solar-ess]] 4편)

$$P = P_{rated} \times \frac{GTI}{1000} \times (1 - 0.0037(T_{cell} - 25)) \times 0.85 \times k_{region}$$

| 항 | 의미 | 값·출처 |
|---|---|---|
| GTI | 경사면 일사량(W/m²). 날씨·시간·계절이 모두 들어 있음 | Open-Meteo, 키 없이 15분 단위 |
| 온도 감쇠 | 셀 온도 1°C 상승당 0.37% 감소 | |
| 0.85 | 시스템 손실(컨트롤러·배선·오염) | |
| k_region | 기상 데이터에 빠진 도심 먼지·그늘 보정 | 0.86~1.03, 지역 PSH 통계에 맞춤 → [[peak-sun-hours]] |

## 변천
1. v1: `정격 × sin(태양고도) × 날씨계수(맑음 1.0 / 구름 0.4 / 비 0.15)` — 방위 무시
2. v2: 태양 방위각과 패널 방향 반영
3. 최종: 실측 GTI 기반 위 식

## 대체 계산 (API 실패 시)
지역 기후 평년값 사용: 장마(6월 말~7월 비 확률↑), 영동 겨울 건조·맑음, 제주 겨울 흐림, 봄 황사(서해안·내륙 감쇠↑), 기온 1991~2020 평년 ±4°C.
- 함정: 해가 동·서에 있을 때 입사량을 거의 0으로 계산해 발전량이 절반이 됨. 정식 입사각 공식 + 대기 감쇠로 목표 ±5% 이내로 수정 → [[simulation-validation]]
