# 태양광 ESS 시뮬레이터

환경공학과 학생으로서 약 6개월 동안 진행한 태양광 모니터링 프로젝트. 실물 하드웨어로 시작했다가 포기하고, 전국 10개 지역을 재현하는 시뮬레이터와 ESS 대시보드로 방향을 바꿨다. 현재(6개월차)는 시뮬레이터 보정 단계.

## 핵심 질문
"날씨와 계절, 지역에 따라 발전량과 배터리가 어떻게 움직이는가?" — 처음엔 "내 패널 하나"였으나 2편에서 질문 자체를 바꿨다.

## 타임라인

| 시기 | 단계 | 결정·사건 | 원본 |
|---|---|---|---|
| 1개월차 | 계획 | 10개 에픽으로 세분화, 센서 후보 비교 | 01 |
| 1~2개월차 | 하드웨어 | 부품 고장, 출력 미미, 설치 장소 문제 → **포기** | 02 |
| 2개월차 | 시뮬레이터 v1/v2 | `suncalc` + 날씨 계수 → 방위각 반영, 단위 테스트 23개 | 03 |
| 3~4개월차 | 현실화 | 10개 지역, Open-Meteo GTI, 지역 보정계수, 평년값 대체 계산 | 04 |
| 4~5개월차 | 클라우드 | GCP Scheduler + Functions + Firestore, 자체 저장·조회 API | 05 |
| 3~5개월차 | 대시보드 | HTML → React+Vite, Express+MongoDB, ESS 카드 | 06 |
| 6개월차 | 검증 | 2025년 1년치 재현(약 52만 건), 대체 계산 버그 발견·수정 | 07 |

## 구조
- 장치 가정: 200Wp(100W×2, 정남 30°), LiFePO4 12.8V 100Ah(1.28kWh), 부하 낮 20W/밤 10W → [[ess-battery]]
- 발전 모델 → [[pv-power-model]]
- 인프라: Cloud Scheduler(30분) → Cloud Functions → 대시보드 서버, 상태는 Firestore. 로컬은 MongoDB(Docker), `--interval 1`로 고속 실행
- 그림: `raw/solar-ess/images/architecture.svg`, 차트 생성 `images/make_charts.py`

## 주요 결과 (07편)
- 지역별 연평균 발전시간: 서울 3.2h, 부산·목포 3.9h — 통계 목표와 일치 → [[peak-sun-hours]]
- 봄 ≥ 여름 (장마·고온·30° 경사)
- 배터리 가득 참 13~20%, 바닥남 서울 6.8% / 부산·대구·제주 0%, 겨울 약 10% 시간 0°C 이하 충전 차단
- 대체 계산이 발전량을 절반만 내던 버그 — 테스트 38개가 못 잡음 → [[simulation-validation]]
