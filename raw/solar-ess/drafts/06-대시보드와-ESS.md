# 6편. 대시보드와 ESS

데이터가 쌓이기 시작하자 다음 질문은 '이걸로 무엇을 판단할 수 있나'였습니다. 저는 배터리를 작은 ESS(에너지 저장 장치)로 보고, 낮에 남는 전기를 저장했다가 밤에 쓰는 흐름을 보여 주는 대시보드를 만들었습니다.

## 만든 순서

| 순서 | 한 일 |
| --- | --- |
| 1 | HTML 대시보드로 첫 화면, 이어서 React + Vite로 옮김 |
| 2 | Express + MongoDB API 서버 구축, 분석 차트 12종과 상세 보기 추가 |
| 3 | 분석 카드를 실제 API 데이터에 연결, 실시간 갱신 |

## ESS 관점에서 보는 카드

- **에너지 흐름:** 패널 → 배터리 → 부하로 지금 전기가 어디로 가는지
- **배터리 충전량(SoC)과 충·방전 전력:** 하루 동안 채워지고 비워지는 모양
- **배터리 상태 분포:** 충전·방전·대기가 각각 몇 % 인지
- **배터리 온도:** 겨울에 0°C 아래로 내려가 충전이 막히는 시간
- **시간대별·월별 발전량, 일사량과 발전량의 상관관계**

## ESS가 던지는 질문

이 장치는 하루에 약 370Wh를 씁니다(낮 20W × 13시간 + 밤 10W × 11시간). 배터리는 1.28kWh라서 맑은 날 하루 발전량이면 충분히 채우고 남습니다. 그렇다면 배터리는 얼마나 가득 차 있고, 얼마나 바닥날까요? 답은 1년치를 돌려 본 7편에 있습니다.
