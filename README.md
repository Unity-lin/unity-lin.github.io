# Unity-lin.github.io

프로젝트 노트를 기록하는 개발 블로그 → https://unity-lin.github.io/

## 로컬 실행

```bash
uv tool install zensical==0.0.72
zensical serve --open   # http://localhost:8000
```

## 새 글

`docs/blog/posts/YYYY-MM-DD-slug/index.md` 를 만들고 front matter(`date`, `slug`, `categories`)를 적은 뒤 `main`에 push하면 자동 배포됩니다.
